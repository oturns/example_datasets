# California Collisions

this is an extract from the California Statewide Integrated Traffic Records System [(SWITRS)](https://www.chp.ca.gov/programs-services/services-information/switrs-statewide-integrated-traffic-records-system/). It contains collisons from 2011-2023 with a subset of the original columns.

**note**: the SWITRS system has been deprecated and these data are now provided as the California Crash Reporting System [(CCRS)](https://data.ca.gov/dataset/ccrs)
